# JobTracker

A full-featured job application and productivity tracker built in Java. This project was built progressively to learn Java backend development from fundamentals to Spring Boot.

## Project Structure
- **console-app** - Console-based Java application using raw JDBC and MySQL
- **spring-boot** - REST API built with Spring Boot, Spring Security and JWT

## Tech Stack
- Java 17
- MySQL
- Maven
- Spring Boot
- Spring Security + JWT
- Spring Data JPA + Hibernate
